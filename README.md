# momon-releases

Public installers and Docker images for [Momon](https://github.com/dozer54321/momon).
Source stays private. This repo exists so a VPS can install and update
without a GitHub token or SSH key.

```bash
curl -fsSL https://github.com/dozer54321/momon-releases/releases/latest/download/momon-linux-setup.sh | sudo bash -s -- yourmomon.top
```

First account you create is the admin. Then signup closes. Open Studio
in the footer to rewrite the page.
